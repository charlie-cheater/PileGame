# 节点:关卡生成算法(仿真玩家代理 × 渐进式规划器)
> 状态:🟡 求解器①②③④已实现并迭代(③决策扫描梯 v1,2026-11-23);「需更多资源的 match」建模待裁定;⑤预期对账与规划器未动工
> 确认:2026-11-21(来源:用户会话指示);结构细化 2026-11-22~23

## 内容(已确认)

**定位:设计性系统,非验证性求解器。** 传统求解器(最短时间找解 / 解数评难度、依赖完整关卡数据)被明确否定为目标;本系统为**尽可能符合人类行为模式的仿真玩家代理**,与**渐进式关卡规划器**构成闭环:

- **代理四要素**:参数集(人格档位)、内部状态、评估行为、操作行为
- **基于有限的、不完整的关卡进行操作**:给出可能的操作 + 操作后的游戏状态变化 + 对难易度的感知
- **反馈闭环**:上述数据作为关卡规划器的输入,渐进式评估并生成关卡后续内容

**求解器执行循环(2026-11-22 定稿,已实现①~④):**
①感知 → ②分析 → ③决策 → ④操作 →(⑤预期:前向模型已由决策产出的 forecast 承载,对账/惊讶度未实现)→ 回①;迭代单位 = 1 次拾取及其结算;出口 = 清空/槽满判负

**求解器设计结构(已实现,2026-11-23):**
- **感知边界**:感知集 = 有可见像素的 pile 牌(exposedArea > 0)+ 槽内牌;身份识别阈值 0.25(占位,两段式待定);未识别牌拷贝遮蔽 elementId;主观视图复用 Tile/TileDerived(拷贝 + 子集重算),隐藏牌对代理不存在
- **v3 等价定理背书**:感知子集重算的覆盖并集 = 真实并集 ⇒ 主观可点性精确等于真值(不确定只残留在身份与隐藏节点存在/揭示)
- **分析算子**(2026-11-23 设计者审阅后收敛:对外仅 `analyze()` 一个入口,各报告为 `AnalysisResult` 子属性 reveal / groups / mate / matches;分析只接收主观视图,与真值的对账归 Runner 驱动侧与 tests):遮挡边/自建深度/揭露闭包(传递闭包大小)/可点性;同类归组(已识别牌按元素分组);揭露效能(独占遮挡口径:至少一像素仅由它覆盖,与移除语义精确对应;v1.6 起含**独占面积数据**——pair 分布保留 + 合计标量,消费端决定聚合/加权);匹配消耗(启动牌 × 目标牌:启动牌 = 配对中获取成本最低者,**槽内牌 = 成本 0 的启动牌**;获取成本 = 1 + (闭包+深度)/2 双口径平均;资源不足仍计算);伴成本 v1 单跳 flat(槽内 0/最廉 flat/环境物价回落)为**正式口径**(2026-11-23 回退裁定)——递归定价(遮挡者成本递归,深度 ≤3 + 回环切断回落 v2.2)经探索因分化过剧回退,**另档保留待评估**(acquireCostR/matchCostR;拓扑事件流挂引擎);**伴去向四分类**(2026-11-23 裁定:配对负担不折叠进成本,只作结构数据)——闭包成员按伴的位置分 ready 就绪 / contained 自含(伴在同一闭包内)/ external 外联(伴埋在闭包外)/ unknown 未知,以 `closureMates` / `dispositionCount` 记录,供决策按需消费
- **决策 v1 = 扫描梯瀑布**(`Ladder.ts`,2026-11-23 定稿):决策以「扫描梯」模式围绕分析数据思考——梯为有序、可插拔的数组,依序过梯、首个非空胜出、全空走内置兜底;每梯产出 **AgentOperation = 移除动作 + 原因 + 预期**(结构化:rule / utility / runnerUp / chain;预期 = pairCompletes / slotAfter / exposes / confidence / forecast),预期即⑤阶段的对账面;Runner 增 v2 决策轨,随机 / 见对先拿策略保留为对照基线
- **梯序(休闲基线)**:slot-close(闭合槽内半张)→ pair-complete(双亮对,P2 折叠)→ chain(借槽两步闭合)→ wander(无信号随机)。slot-close 先于 pair-complete 为裁定项:设计稿原序经平盘推演证伪(连续持半致槽满);cheap-hold / dig / forced 待实现
- **梯内平级择优 = 揭示预演**(`simulateReveal`,主观前向模型,深度 1):假想移除候选,其**直接覆盖**的目标二分——预演后变可点者按激活计值(closes 1.0 / pairs 0.8 / lone 0.2),仍被压者记 near(剩余遮挡者里有可点牌)/ far;效能 = 0.7 × Σ激活 + 0.3 × near 张数,**求和不归一**(揭 3 张优势牌好过 2 张;布局规则下单次揭露 ≤ 4 张);平分取 tileId 小者。预演对可点性是乐观估计(隐藏牌不在感知集)——即⑤惊讶度的来源;hiddenRisk 字段预留、暂恒 0(设计者另有计划)
- **chain 梯(借槽两步闭合)**:拿一张可点牌,它揭出的牌下一步拿走即可闭对;两类同梯、按效能择优——slot(与槽内已有半张闭合)/ pair(与本次拿的这张闭合);可用性是开关而非打分项:空槽 < 2 整梯让位(按当前容量计,槽位扩充道具下自动适应);pair 加分 0.3(裁定「槽位干净更重要」)。更深的链(深度 3)暂不做
- **语料**:RandomFill(骨架 → FULL 随机配对,seed 确定);测试/编辑器盘面统一 test_layout.json + seed 7
- **debug 验收**:编辑器选中交互(点牌显示效能/匹配消耗两行信息 + 四层高亮:选中/直接遮挡/揭露闭包/匹配搭档)

**配对形态(现阶段锁定):全图匹配(FULL + FULL)**
- 同元素牌完全可互换,不存在"指定的另一半";可解性只取决于元素→位置分配
- 二分对(L/R)延后:`tile.ts` 数据契约(variant/canPair)已支持,启用无需改逻辑
- **元素重复度(每元素 2/4/6 张)成为内容设计主轴**:批量实证(2026-11-23,test_layout 盘,7×5 + 见对先拿通关率 29% vs 35×1 纯随机 0%)

**已推导的结构性质(实现基础,见 background)**
- P1 单调性:移除只增可点集 → 已可点牌永远可点
- P2 双亮对折叠:两张可点的同元素牌立即成对移除永不变坏(人类同样"见对先拿")
- P3 状态归约:模拟/搜索状态 = 已移除集;槽内容可从中导出,容量约束 = 开对 ≤ 3

**混合架构分工**:正确性(必可解)由构造保证(逆向/增量放置 + P1/P2);代理负责体验评估;验证性搜索降级为终检安全网。

**难度观**:难度 = 代理与内容交互的**体验轨迹**(张力曲线、峰值槽压、被迫感、犹豫度),非关卡内禀标量;目标映射情绪锚点(慢节奏、失败温柔),非最大化难度。

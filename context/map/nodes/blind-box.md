# 节点:盲盒载体

> 状态:⛔ **已搁置(2026-11-19)**——实现改采真实麻将牌面体系(饼/条/万/风/箭,用户决策);本概念留档备查,内含玩具收集的设想仍可衔接图鉴/玩具经济节点
> 确认:2026-11-16(来源:用户灵感——"麻将造型 × 健达奇趣蛋式盲盒")

## 内容(已确认)

**五要点(用户原意):**
1. **保留麻将基本造型**(等大矩形、有厚度)→ 延续首批概念图关卡设计的整齐清晰(M1/M5)
2. 牌体换成"健达奇趣蛋式盲盒"(借**概念**,非品牌——避免蛋形+红白条纹等可识别组合)
3. **印花分类**:盒面印花 = 麻将牌面同位物,承担匹配分类(体系升级为二分符号,见 [split-symbol.md](split-symbol.md))
4. **开盒视效**:合并消除瞬间触发开盒动画(详见 [reward-loop.md](reward-loop.md))
5. **内含童年玩具** → 收集元素(详见 [toy-economy.md](toy-economy.md))

**优势保全论证(麻将 M1~M7 全继承):**

| 优势 | 盲盒方案表现 |
|---|---|
| M1 堆叠物理 / M5 整齐清晰 | ✅ 造型同构,关卡设计语言原样继承 |
| M2 图案分类 | ✅ 印花承担 → 升级为二分符号 |
| M3 零门槛认知 | ✅ 盲盒=当代认知 × 奇趣蛋=童年记忆,双命中 |
| M4 材质温度与声音 | ✅ 纸盒/糖果盒质感 + 开盒"嚓啦-啵"声 |
| M6 收集完型 | 🚀 超级加倍:消除=拆礼物,玩具飞入图鉴 |
| M7 配对规则同源 | ✅ 盲盒文化原生对应:"同款/集齐一套" |

**结构性贡献:** 打通"核心玩法 ↔ 收藏图鉴"(消除循环即图鉴生产线),原麻将方案无此连接。

# 节点:奖励循环

> 状态:🟡 **v1 已实现(2026-11-19)**:两半吸引靠拢(0.12s)→ 放大爆闪 → 收缩消失 → 槽位紧凑滑移;开盒/玩具弹出(本节点核心拍)未做
> 确认:2026-11-16(来源:盲盒灵感 + 二分符号推演)

## 内容(已确认)

**奖励链(每次消除即一次拆礼物):**

```
配对成立 → 两半互相吸引拼合(嚓!)→ 完整元素发亮 → 开盒(嚓啦-啵)→ 玩具跳出 → 飞向图鉴
```

- 配对 = 拼合 = 完整 = 揭晓:叙事链条自洽,与"集两半拼出完整玩具入图鉴"语义一致
- 稀有款加小闪光;普通款保持轻量
- **约束:不破坏"慢"基调**(情绪锚点)——奖励是温柔的惊喜,不是老虎机的爆裂

# 麻将元素优势解构(M1~M7)

> 背景知识:替换麻将元素的选型依据与论证基础。
> 应用论证见 [../map/nodes/blind-box.md](../map/nodes/blind-box.md) 与 [../map/nodes/split-symbol.md](../map/nodes/split-symbol.md);完整探索过程见 [stacking-element-exploration.md](stacking-element-exploration.md)。

## 解构(为什么麻将统治了堆叠消除品类)

| # | 优势 | 说明 |
|---|---|---|
| M1 | 可堆叠物理性 | 等大、扁平、有厚度的刚体 → 多层遮挡堆叠成立,2.5D 厚度感 |
| M2 | 分类图案体系 | 有限集合、图案差异一目了然 → 匹配判定,小尺寸可读 |
| M3 | 零门槛认知 | 全民熟悉,无需教学("认识这个东西") |
| M4 | 材质温度与声音 | 骨/玉温润 + "嗒咔"碰撞声(情绪锚点的听觉通道) |
| M5 | 视觉清爽高密度 | 白底彩纹+深桌面,40 张同屏不乱 |
| M6 | 收集完型心理 | 完整小物件,凑对/清空的完型满足 |
| M7 | 配对规则同源(用户补充) | 麻将自身规则含"对子/碰牌"(连连看直接配对消除)→ 自带"该配对"认知预设,玩法动词免教学("知道拿它做什么") |

M3 与 M7 互补:M3 是"认识这个东西",M7 是"知道该拿它做什么"——合起来才是完整认知优势。

## 替换原则

**结构性保住 M1/M2/M5/M6/M7,用童年夏日物件重新供给 M3/M4。**

# 参考分析 01 · 原作牌堆概念图

> **背景资料**:以下为**参考原作**的概念图分析(非本项目最终设计);确认采用的结论见 `../map/nodes/gameplay-core.md`。
> 原图:[../assets/concept-pile-01.png](../assets/concept-pile-01.png)(用户提供,2026-11-16 归档)

## 画面要素

- 竖屏(约 380×500),深墨绿呢绒桌面背景 + 圆角边框
- 主体:麻将样式白底圆角牌,带厚度侧面(2.5D 伪立体),轻微投影
- 纵向 6~7 层、全场约 30~40 张牌,**上层遮挡下层**,松散交错摆放(非规整网格)
- 右上角一张牌(虎头图案)高亮发亮 → 选中/可消除状态提示
- **无槽位栏、按钮、计分 UI** → 仅核心玩法区概念,正式版需补充

## 牌面种类(图中可见)

| 类别 | 内容 |
|---|---|
| 风字牌 | 西 ×2+、北 |
| 番牌 | 發 ×多张 |
| 汉字数字牌 | 四 ×3、三 ×2(蓝色字) |
| 花牌 | 梅、兰 ×2+、菊、竹(梅兰菊竹) |
| 吉祥牌 | 福(倒福,红)、秋(配枫叶)×2、**虎头图案 ×3**(卡通橙红虎头) |
| 筒子牌 | 蓝绿圆点(左下见九筒样式) |
| 索子牌 | 绿色条状 |
| 其他 | 红色方框花纹牌 ×1(待定) |

## 可推断机制

1. 多层遮挡堆叠;**仅顶层/未被遮挡的牌可点击**
2. 同图案牌配对/凑数消除(**2 消还是 3 消待定**,图中无槽位栏佐证)
3. 目标 = 从上至下拆解牌堆、清空获胜 → 对应项目名 PileDisassemble
4. 中国风麻将题材,面向休闲用户

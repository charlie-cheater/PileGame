## 内容(已确认)

```
启动页(splash)→ 主页(home)→ 游戏场景加载页(开门动画)→ 游戏场景(game)
```

**启动页**:木牌 Logo + slogan 引言卡 + 「發」牌弹跳进度条(50.00%)+ 健康游戏忠告(合规必备);无按钮
**主页**:竹林楼阁 + 熊猫吉祥物(抱「發」牌);左列 每日胜利/主题/分享(红点),右列 排行榜/收藏奖励;底部金色卷轴 CTA「第 N 关」(读存档);左上设置
**开门加载页**:双开门张开程度 = 加载进度(红棕门扇 + 回纹门钹,门缝透光);无传统进度条;可挂"门神合璧"彩蛋(见 split-symbol)
**游戏场景**:顶部 第N关 + 脑力 + 暂停;槽位托盘 4 格;牌堆区;底部道具三件套 + 引导气泡

**周边系统清单**(入口在主页):每日任务、排行榜、收藏图鉴、主题皮肤、分享、设置

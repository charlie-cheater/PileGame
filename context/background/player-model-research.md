# 玩家仿真代理研究(EDPCG / simulated playtesting)

> 背景知识:仿真玩家代理 × 渐进式规划器的学术脉络与设计素材。2026-11-21 会话归档;设计定位见 [map/nodes/level-generation.md](../map/nodes/level-generation.md)。

## 与验证性求解器的分野

| 维度 | 验证性求解器 | 仿真玩家代理 |
|---|---|---|
| 目标 | 最短时间找解 / 解数评难度 | 复现人类行为模式,产出体验信号 |
| 输入 | 完整关卡 | 部分/不完整关卡,可增量操作 |
| 时间方向 | 一次性、终局式 | 在线、渐进,与规划器闭环 |
| 输出 | 有/无解、见证序列 | 动作分布 + 状态变化 + 难度感知 |
| 最优性 | 追求完备/最优 | 有界理性(satisficing),允许失误 |

核心命题(EDPCG):**难度不是关卡的内禀属性,而是代理与内容交互产生的体验轨迹**——用计算模型(代理)代替人类被试来评估内容。

## 学术脉络

- **Experience-Driven PCG**(Yannakakis & Togelius):用玩家体验计算模型驱动内容生成/适应——本闭环的标准学名
- **RL 人类风格代理自动 playtesting**(de Woillemont 等,AIIDE 2022):训练复现玩家风格的代理,在未见关卡上产出类人指标
- **Procedural personas**(模仿学习):人格化代理自动测试生成内容
- **MGP-IRL**(多目标概率逆强化学习):从真实玩家数据逆向学行为——**后期校准路线**(上线后用微信小游戏行为数据校准代理参数,从手设人格进化为数据驱动人格)
- 文献共识痛点:合成代理要么过优要么过随机,人类相似性最终需真实数据锚定 → **初版参数手设 + 预留校准接口**是务实路径

## 代理设计要素(本作语境)

本作**全可见**(被遮挡牌 dimmed 但可见)→ 代理瓶颈是**注意力/工作记忆**,非信息获取。

- **参数集**:前瞻深度 d(休闲玩家 1~2)、失误率 θ、记忆容量 M、风险偏好;~~完形敏感度~~(现阶段全图匹配,L/R 识别轴删除)
- **内部状态**:salience 表(暴露面积天然是显著度特征,`Visibility.exposedRatio` 可直接采)、同类牌位置记忆、槽压感知、犹豫度(决策效用差/熵)
- **评估行为**:扫描可点集 → 显著度排序;找同类(搜索成本 = 同类剩余张的埋藏结构);风险估计(开这张要占槽多久);被迫感(无害动作数)
- **操作行为**:效用 + softmax 随机(同 seed 可重放);完对优先(= P2 的人类版,"见对先拿");失误通道(按 θ 采样次优选择)

## 难度感知信号(代理 → 规划器的反馈契约)

- **逐步**:动作集 + 效用分布(行为轨迹)、执行动作、状态增量(槽占用 / 新解锁 / 余量计数)
- **难度向量**:槽位占用峰值、可完对数、被迫动作标志、犹豫度(决策熵)、在槽牌的同类深埋度、失误概率、张力事件(槽满前一步救场)
- **轨迹聚合**(批级输入):峰值槽压曲线、张力 episode 分布、预测通关率、卡点位置

## 闭环几何(未决,算法设计定夺)

- **前向生长**:规划器逐批放置内容,代理在"生长中的盘面"模拟游玩前缀
- **逆向构造**:按放置波次(`Depth.waves` 降序)反向放对,代理评估"以此为局面,人类感受如何"(P1/P2 保证增量放置的健全性)
- **混合**:逆向构造保证可解性骨架,前向代理校准难度曲线

## 工程落点

- **Board 即环境**:`clickableTiles() / getDerived() / getVisibleState()` 即代理感知 API;代理单步 O(可点数 × 启发式),远轻于验证器,无热循环性能风险
- 混合架构:构造保证正确性(P1/P2),代理负责体验,验证搜索终检兜底
- 难度目标映射情绪锚点:张力曲线受控、失败温柔,非最大化难度

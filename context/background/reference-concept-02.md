> **背景资料**:以下为**参考原作**的界面分析(非本项目最终设计);确认采用的结论见 `../map/nodes/scene-flow.md`。注意:《对子乐消消》为参考原作名,本项目正式名称待定。
> 原图:[splash](../assets/screen-splash.jpg) · [home](../assets/screen-home.jpg) · [loading](../assets/screen-loading-game.jpg) · [game](../assets/screen-game.jpg)(用户提供,2026-11-16 归档)

## 场景流程

```
启动页(splash)→ 主页(home)→ 游戏场景加载页(开门动画)→ 游戏场景(game)
```

## 1. 启动页(splash)

- 翠绿背景(#2E9E6B 级,轻微径向渐变)+ 低透明度(~10%)麻将牌 45° 水印散布,避开中心
- 木牌 Logo「对子乐消消」(~8-22% 高度):金黄字 + 橙描边,弧形排列,竹叶装饰,可做摇摆动画
- Slogan 引言卡(中式回纹角框 + ◇◇◇ 菱形分隔):「"慢下来才能看见每一步里藏着的小小答案。"」
- 加载区(~63-74%):白色「發」小牌(-15° 倾斜,弹跳动画+落地阴影)+ 圆角胶囊进度条(深棕底槽、橙黄渐变填充、分段果冻质感),进度文字「50.00%」居中于条上
- 底部(~76-88%):《健康游戏忠告》三行合规文案
- 无任何按钮;加载完成 → 淡出进主页

## 2. 主页(home)

- 背景:蓝天白云 + 两侧竹叶垂入;中景中式两层楼阁(青绿瓦/朱红柱/米白墙/雕花圆窗)
- 中轴:**熊猫吉祥物**(头顶竹叶、怀抱绿色「發」牌)→ 待机呼吸动画候选
- 顶部居中:Logo 木牌;左上:**设置**(黄色圆角方块+白齿轮);右上:微信胶囊(安全区避让)
- 左列(自上而下):**每日胜利**(剪贴板+对勾)/ **主题**(锦盒)/ **分享**(礼盒,红点提醒)
- 右列(与左列对称):**排行榜**(三奖杯柱)/ **收藏奖励**(红色礼盒金丝带)
- 底部居中主 CTA:**「第6关」金色卷轴按钮**(祥云纹两端,文字读存档动态显示)
- 前景:水面倒影 + 石墩步道 + 左右下角栏杆
- 美术:Q 版 3D 卡通渲染,主色 天空蓝 / 青绿 / 橙金 / 米白朱红

## 3. 游戏场景加载页(开门动画)

- 视觉隐喻:**双开门张开程度 = 加载进度**,无传统进度条
- 左右红棕门扇(#8B3A2A 级)随进度水平滑开;中缝竖贯发光(青绿室内 + 金色物件边缘)
- 中央圆形门钹/铜钱装饰:深棕外环 + 米白回纹盘(#F7EBCB)+ 黄铜环 + 发光黄钮(#F5C842,外发光)
- 大圆窗棂(方格镂空,露出绿底)+ 顶部/底部竖栅条(每侧 4 条)
- 门后:青绿庭院 + 底部金色立绘一角(疑似角色,文字「…影」)
- 实现:门扇 Sprite 按 progress 水平位移(cc.tween);门缝 Additive 发光条;完成 → 圆盘闪光 → 淡入游戏场景

## 4. 游戏场景(game)—— 信息量最大

### 顶部信息栏
- 左上:「第6关」(黄描边字);中上:「脑力:0」(**脑力 = 资源/货币**);右上微信胶囊
- 左侧偏下:暂停按钮(黄色圆角方块 + 双竖线)

### 槽位栏(关键!)
- 顶部栏下方居中:棕色木纹托盘,**4 个格子**(棕色分隔线)
- 结合游戏名「**对子**乐消消」→ 消除单位倾向 **对子(2 张相同即消)**
- ⚠️ 视觉模型曾推测"凑 4 张相同消除",与游戏名"对子"矛盾;2 消更符合命名与 4 格容量设计,**待最终确认**

### 牌堆区
- 中部大面积多层错位堆叠,上层压下层;**被遮挡牌显示绿色牌背、不可点击**
- 牌面种类(较概念图 01 新增):**灰猫照片牌**、红脸老虎、蓝色牛头(动物/照片牌)+ 筒子(二筒、八筒)/ 条子 / 汉字牌(西、北、三、六、梅、伍、中-红、發-绿)

### 底部道具栏(三道具 + 引导气泡)
| 道具 | 图标 | 角标 | 备注 |
|---|---|---|---|
| 洗牌 | 黄色循环箭头 ↺ | 绿色「+」 | 重排牌堆 |
| 提示 | 灯泡+闪电 💡⚡ | **红色「4」**(剩余次数) | 下方文字「提示」 |
| 撤回 | 黄色回退箭头 ↩ | 绿色「+」 | 槽位牌放回原位 |
- 「+」角标 = 可购买/看广告补充;气泡「试试道具吧」= 新手引导

### 背景
- 深墨绿绒布(麻将桌质感)+ 四角竹叶装饰;顶部刘海挖孔(机型适配)

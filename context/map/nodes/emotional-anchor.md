# 节点:情绪锚点(设计北极星)

> 状态:✅ 已确认
> 确认:2026-11-16(来源:用户口述——原作背景音效唤起的童年记忆)

## 一句话

**让玩家回到那个阳光明媚、鸟鸣穿风的夏日午后——把麻将当积木、无忧无虑的童年时光。**

## 原始场景(用户记忆)

- 夏日午后,阳光明媚;坐在床边,吹着(穿堂)风
- 户外传来**城市常见鸟类的鸣叫**(模拟或录音)
- 用麻将牌**当积木**堆着玩
- 情绪:无忧无虑、安全、慢、温暖、明亮

## 为什么是核心(三条论证)

1. 原作视觉图并未传达此情绪,**它主要靠声音建立** → 声音是情绪第一载体,不是配菜
2. 原作启动页 slogan「慢下来才能看见每一步里藏着的小小答案」是同一情绪的文本证据——"慢"是刻意设计
3. 玩法形态与童年行为同构:"麻将当积木" ↔ "多层堆叠、逐层拆解"

## 设计转译(指导原则)

| 维度 | 原则 | 候选方向 |
|---|---|---|
| 声音·底层 | 环境音优先于音乐 | 城市常见鸟鸣循环(麻雀/白头鹎/珠颈斑鸠/乌鸣/燕子等),音量贴耳不抢戏 |
| 声音·氛围层 | 强化夏日户外感但克制 | 远处蝉鸣、微风声、街道白噪音(⏳ 待定) |
| 声音·反馈 | 拟真、温润 | 麻将/纸盒"嗒咔、嚓啦"声;消除轻柔;避免赌场式音效 |
| 视觉·光线 | 夏日午后暖光 | 暖色温、柔和阴影;避免硬光/夜景/高对比刺激 |
| 视觉·动效 | 微风感 | 竹叶轻摆、水面微光、云缓移;缓动柔和、时长偏长 |
| 节奏 | 慢、无压迫 | 不设苛刻计时;失败温柔;引导轻量 |
| 交互 | 安全感 | 可暂停、可撤回,尊重玩家节奏 |
